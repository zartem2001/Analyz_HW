# Программа-анализатор — BlockingQueue и многопоточность

## 📋 Описание задачи

Программа генерирует **10 000 текстов** длиной **100 000 символов** каждый 
из символов `'a'`, `'b'`, `'c'`. Необходимо найти текст с **максимальным 
количеством** каждого из символов — при этом для каждого символа работает 
**отдельный поток**.

Хранить все тексты в памяти нельзя (около 1 млрд символов). Поэтому используется 
**конвейерная обработка**:
- Один поток **генерирует** тексты и кладёт их в три очереди.
- Три потока-**анализатора** читают свои очереди и ищут максимум.

Очереди — **блокирующие** (`BlockingQueue`) с ограничением на 100 элементов.

## 🎯 Цель

Отработать:
- Использование `BlockingQueue` (`ArrayBlockingQueue`);
- Паттерн **Producer-Consumer** (производитель-потребитель);
- Организацию конвейерной обработки данных;
- Ожидание завершения потоков через `join()`;
- Отправку **стоп-сигнала** для корректного завершения потребителей.

## 🛠️ Используемые технологии

- Java 17+
- Spring Boot
- `BlockingQueue`, `ArrayBlockingQueue`
- `ThreadLocalRandom`
- `Thread`, `Runnable`
